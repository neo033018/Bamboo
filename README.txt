BAMBOO V3 — interactive visual prototype
Open index.html in Chrome or Safari. No installation required.
Features: responsive colorful sections, English word cards (Chinese/Russian), browser voice, speech recognition where supported, mini English lessons, XP/coins/shop, challenges, themed discovery, sample AI Bamboo chat.
Limitations: AI chat is a scripted demo; no backend or real AI connected. Browser speech voices vary by device. Pronunciation recognition is not a reliable phoneme-level score. Block world is decorative, not playable 3D. Game characters and art are original-style concepts, not licensed Minecraft/comic IP.
Progress is saved in localStorage on the same browser/device.
